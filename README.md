# Gerador de Senha Aleatória

Este é um projeto simples de **Gerador de Senha Aleatória** desenvolvido com **HTML5**, **CSS3** e **JavaScript**. A aplicação permite que o usuário gere senhas aleatórias com comprimento entre 5 e 25 caracteres. As senhas geradas são compostas por uma combinação de letras maiúsculas, minúsculas, números e caracteres especiais, garantindo maior segurança e complexidade.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação do conteúdo da página e dos elementos da interface.
- **CSS3**: Estilização da página para criar uma interface simples, limpa e agradável.
- **JavaScript**: Lógica para gerar senhas aleatórias, além de implementar a interatividade necessária para a aplicação.

## 📱 Funcionalidades

- **Geração de Senha Aleatória**: O usuário pode gerar senhas com comprimento variável entre 5 e 25 caracteres.
- **Personalização de Caracteres**: As senhas incluem letras maiúsculas, minúsculas, números e caracteres especiais para maior segurança.
- **Interface Simples e Intuitiva**: A interface foi desenhada para ser fácil de usar, permitindo que o usuário gere e visualize rapidamente a senha gerada.

## 🎨 Personalização

O design básico foi criado com **CSS3**, mas você pode personalizar a aparência do projeto facilmente editando o arquivo `styles.css`. Para ajustes na lógica de geração das senhas, basta modificar o arquivo `script.js`.
