Gerador de Senha Aleatória
Este é um projeto simples de Gerador de Senha Aleatória desenvolvido com HTML5, CSS3 e JavaScript. A aplicação permite que o usuário gere senhas aleatórias com um comprimento entre 5 e 25 caracteres. As senhas geradas são compostas por uma combinação de letras maiúsculas, minúsculas, números e caracteres especiais para garantir maior segurança.

🚀 Tecnologias Utilizadas
HTML5: Estruturação do conteúdo da página e dos elementos da interface.
CSS3: Estilização da página para garantir uma interface simples e agradável.
JavaScript: Lógica para gerar senhas aleatórias e implementar a interatividade.
📱 Funcionalidades
Geração de Senha Aleatória: O usuário pode gerar senhas com comprimento entre 5 e 25 caracteres.
Personalização de Caracteres: As senhas incluem letras maiúsculas, minúsculas, números e caracteres especiais.
Interface Simples e Intuitiva: A interface é fácil de usar, permitindo ao usuário gerar e visualizar a senha rapidamente.

🎨 Personalização
O estilo básico foi feito com CSS3, mas você pode personalizar a aparência do projeto facilmente editando o arquivo styles.css. Para ajustar a lógica de geração de senhas, basta modificar o arquivo script.js.
